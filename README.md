# po-bitbucket-copy

Object-oriented programming in Java: 5 exercise lists, a test and exam tasks. 63 commits.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021–2022 (first commit on 8 October 2021, last commit on 31 January 2022).

## Contents

- `src/lista00/`, `lista01/`, `lista02/`, `lista04/`, `lista05/`: solutions of the exercise lists.
- `src/kolokwium/` and `kolos/`: the test (7 Java files each).
- `src/eeee/`: exam practice (`egzamin1`–`egzamin5`), `IntSequence` and a scratch file.
- an exam folder in `src/` with tasks `Z1`–`Z3`.
- `out/`: compiled `.class` files; `.idea/`, `java.iml`: IntelliJ IDEA project files.

The repository also contains course materials: the task lists in `listyZadan/` (9 PDF files).

## Running

The code needs a Java compiler (JDK), which this machine does not have, so I did not run it in November 2026.
